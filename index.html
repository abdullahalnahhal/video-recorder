    About file support

    PDFs and images render exactly as the original. PowerPoint, Word and Excel files have no pixel-perfect renderer available without a server, so they show a simplified stand-in instead: each slide's text (plus its first picture), the document's text reformatted as a simple page, or a plain data grid for each sheet. Older binary formats (.doc, .ppt, .xls) aren't supported — save/export them as .docx, .pptx or .xlsx first.
